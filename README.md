# نظام إدارة المحلات التجارية ونقاط البيع (Retail POS & Store ERP)

نظام متكامل لإدارة الأنشطة التجارية والمحلات ونقاط البيع السريعة، تم تصميمه بهندسة برمجية حديثة لدعم نموذج السحابي والمحلي (Hybrid Cloud & Offline-resilient) وتجربة مستخدم عربية أصيلة (RTL-First).

---

## 🌟 الميزات الجوهرية للنظام

### 1. نقطة البيع السريعة للكاشير (Fast POS)
- دعم ماسح الباركود الفوري وإضافة المنتجات بمجرد المسح.
- اختصارات لوحة المفاتيح:
  - `F9`: إتمام عملية البيع فوراً وطباعة الفاتورة.
  - `F2`: التركيز على حقل البحث والباركود.
  - `Esc`: إغلاق النوافذ المنبثقة.
- خيارات دفع متعددة: نقداً (كاش)، شبكة / بطاقة، أو بالآجل (ديون على العميل).
- تطبيق الخصومات (مبلغ أو نسبة) وحساب الإجمالي فورياً.
- طباعة فواتير حرارية متوافقة مع طابعات الإيصالات 80mm و A4، مع توليد باركود الفاتورة آلياً.

### 2. إدارة المنتجات والمخزون (Inventory Management)
- إضافة وتعديل وحذف المنتجات والتصنيفات.
- توليد الباركود تلقائياً أو مسحه بالأجهزة المخصصة.
- تحديد سعر تكلفة الشراء وسعر البيع وحساب هوامش الربح.
- تنبيهات ذكية وفورية للمنتجات التي وصلت للحد الأدنى (Low Stock Alerts).

### 3. إدارة المبيعات والفواتير والمرتجعات
- سجل تفصيلي لجميع العمليات مع إمكانية البحث والفلترة.
- إعادة طباعة أي فاتورة سابقة بضغطة زر.
- تسجيل المرتجعات واسترداد الكميات للمخزن مع ضبط الحسابات.

### 4. المشتريات والموردين (Purchases & Suppliers)
- تسجيل فواتير الشراء الواردة وتحديث الكميات بالمخزن تلقائياً.
- تحديث تكلفة الشراء للمنتجات.
- تتبع أرصدة الموردين والمبالغ المستحقة لهم وسدادها.

### 5. العملاء وحسابات الديون (Receivables & CRM)
- قاعدة بيانات العملاء والديون المستحقة.
- البيع بالآجل مع تسجيل الرصيد التراكمي على العميل.
- إصدار سندات قبض وسداد الديون مع تحديث الحساب فورياً.

### 6. المصروفات التشغيلية (Operating Expenses)
- تسجيل بنود المصروفات (إيجار، كهرباء، رواتب، صيانة، نثريات).
- تصنيف المصروفات لحساب صافي الأرباح الحقيقي.

### 7. التقارير المالية والأرباح (P&L & Analytics)
- قائمة الدخل وصافي الربح التقديري:
  $$\text{صافي الربح} = \text{إجمالي المبيعات} - \text{تكلفة البضاعة المباعة (COGS)} - \text{المصروفات}$$
- مؤشرات بيانية لحركة المبيعات خلال الأسبوع والشهر.
- قائمة الأصناف الأكثر مبيعاً والأقل مبيعاً.

### 8. إعدادات المحل ودعم العملات
- تخصيص اسم المحل، الهاتف، العنوان، وتذييل الفاتورة.
- دعم العملات المتعددة (ريال يمني YER، ريال سعودي SAR، دولار USD... إلخ).

## 🏗️ التقنيات المستخدمة (Tech Stack)

- **Backend**: Node.js, Express.js.
- **Database**: SQLite WAL Mode (Better-SQLite3) مع معمارية قابلة للنقل المباشر إلى PostgreSQL في بيئات الـ Multi-Tenant SaaS.
- **Frontend**: HTML5, Modern Tailwind CSS, Lucide Icons, Chart.js, JsBarcode.
